렌탈 설치비는 어떻게 확인하나요?

짧은 답 — 기본 설치가 포함된 상품이 많지만, 현장 상황에 따라 발생하는 추가 작업비는 대부분 별도입니다. "설치비 무료"라는 문구를 봤다면 어디까지가 기본 설치인지를 물어보셔야 합니다.

상세 설명

설치비는 보통 기본 설치와 추가 작업으로 나뉩니다. 기본 설치는 표준 환경에서 제품을 놓고 연결하는 데까지입니다. 문제는 실제 집이 표준 환경인 경우가 드물다는 점입니다.

추가 비용이 자주 발생하는 상황은 제품군마다 다릅니다.

  • 에어컨 — 배관 연장, 벽 타공, 실외기 앵글 설치, 기존 배관 교체
  • 정수기 — 언더싱크 설치, 수도 분기 작업, 배수 연결
  • 세탁기·건조기 — 배수 연장, 적층 스탠드, 기존 제품 수거
  • TV — 벽걸이 브라켓, 벽 재질에 따른 보강 시공
  • 냉난방기 천장형 — 천장 타공, 배관 경로 확보

확인사항

  1. 설치 환경을 미리 알려주세요. 상담 시 사진을 보내면 추가 비용을 미리 안내받을 수 있습니다.
  2. 추가 비용 상한을 물어보세요. "최대 얼마까지 나올 수 있나요?"가 유용한 질문입니다.
  3. 현장 결제 항목을 미리 확인하세요. 설치 당일 예상 못한 지출을 막습니다.
  4. 설치 불가 시 조건을 확인하세요. 특히 언더싱크 정수기와 천장형 냉난방기는 설치가 안 될 수 있습니다.
